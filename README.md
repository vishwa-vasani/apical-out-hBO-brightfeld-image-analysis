# apical-out-hBO-brightfeld-image-analysis

This repository contains all scripts for organoid brightfield image analysis associated with the publication titled "A simplified protocol for the generation of apical-out human bladder organoids in suspension using a rotating bioreactor".

In order to perform image analysis for your organoids, follow the order below:
  1. Uploading all z-stack image files onto Omero. Note fileset unique identifier as well as account number on Omero.
  2. Extended depth of field (EDF) script - to be loaded into Fiji. Change Omero account number to your account number. Upon running the script, it will ask you for fileset unique identifier as well as sigma (blurring parameter). Optimize sigma to get best projection images
  3. Organoid segmentation script - Open this script inside the environment that has Napari and micro-SAM installed. Executing this script will open each image in Napari with raw segments. Edit segments as needed by following instructions on screen.
  4. Adaptive thresholding and plotting script - Load excel sheet generated by [3.] into the script and run all cells.
